# Admin Dashboard

A clean and responsive admin dashboard web application built with HTML, CSS, and JavaScript.

## Features

- **Modern UI** - Clean and professional user interface
- **Asset Management** - Organized structure for icons and images

## Project Structure

```
admin-dashboard/
├── README.md
├── public/
│   ├── index.html      # Main HTML file
│   ├── styles.css      # Global styles
│   └── assets/
│       ├── icons/      # Icon assets
│       └── images/     # Image assets
```

## Getting Started

1. Clone the repository:

```bash
git clone <repository-url>
```

2. Navigate to the project directory:

```bash
cd admin-dashboard
```

3. Open `public/index.html` in your web browser or serve using a local server:

```bash
# Using Python
python -m http.server 8000

# Or using Node.js
npx http-server
```

Visit `http://localhost:8000` in your browser.

## Technologies Used

- CSS3
